# 优化组筛选补充

这个 `README.md` 只负责一件事：**每次任务开始时，先向用户说明这个 skill 的功能，再检查执行所需输入是否齐全。**

## 这个 skill 是做什么的

开场先对用户说明：

```text
这个 skill 的功能是：根据 top 语言筛选需要优化的广告组，并在你确认后同步到在线表格。
开始前我会先检查 3 项必需信息是否已提供：
1. 在线表格链接
2. 本地表格路径
3. top语言
```

## 开场检查规则

每次开始任务时，只检查这 3 项：

1. `在线表格链接`
2. `本地表格路径`
3. `top语言`

规则很简单：

- 三项都已提供：进入下一步分析
- 缺任意一项：先提醒用户补充，不展开后续流程

## 标准话术

### 三项都已提供

```text
已收到本轮任务所需信息：
1. 在线表格链接
2. 本地表格路径
3. top语言

我将继续下一步：先扫描分析 top语言，再给你确认本轮识别方案。
```

### 缺少信息

```text
这个 skill 的功能是：根据 top 语言筛选需要优化的广告组，并在你确认后同步到在线表格。

开始前还缺少以下信息，请补充后我再继续：
- 在线表格链接
- 本地表格路径
- top语言
```

只列实际缺失项。

## 推荐输入格式

### 在线表格链接

```text
https://docs.google.com/spreadsheets/d/xxxx/edit
```

### 本地表格路径

```text
/Users/<你的用户名>/Desktop/ad_group_export_20260430.xlsx
```

获取方式：
① 前往新中台，选择目标 App 和时间范围，导出全部数据到本地
② 按住 Option，两指点击文件，即可看到「将 xx 拷贝为路径名称」

### top语言

支持：

- 中文：`英语`、`西班牙语`、`葡萄牙语`
- 英文：`english`、`spanish`、`portuguese`
- 语言代码：`en`、`es`、`pt`
- 带地区写法：`English (India)`、`西班牙语（美国）`

如果输入带地区，默认只识别主语言，不按地区拆分。

搜索规则补充：

- 在本地表格中识别语言时，短代码只按独立 token 搜索
- 不会因为普通单词里刚好包含代码子串就误判
- 例如 `Personal Plan` 不会因为包含 `pl` 被识别成波兰语

## 三项齐全后的下一步

三项齐全后，再进入正式流程：

1. 扫描分析 `top语言`
2. 回显本轮识别方案给用户确认
3. 汇报筛选结果预览
4. 用户确认后再同步到在线表格

不要在 `README.md` 阶段展开完整执行细节；这里只负责开场说明和输入检查。
